# Cimapp 🏔️

Aplicación web para montañeros y excursionistas: catálogo de cimas de España, gestión de listas personales (favoritas, pendientes y coronadas) y recomendaciones inteligentes impulsadas por Inteligencia Artificial con la API de Google Gemini.

## 🚀 Arquitectura
- **Backend**: Node.js + Express + TypeScript + Google Generative AI SDK (`apps/backend`)
- **Frontend**: React + TypeScript + Tailwind CSS (`apps/frontend`)
- **Especificaciones**: Documentación técnica en la carpeta [`.specs/`](file:///c:/Users/enelf/Desktop/cimapp/.specs/)
